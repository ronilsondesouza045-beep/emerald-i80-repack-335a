# Emerald i80 Repack v1.0.0

Release para testes locais com WoW WotLK 3.3.5a build 12340.

### Destaques
- Correção do falso kick/desconexão observado durante sincronização de addon.
- Teste de múltiplas contas realizado sem reproduzir a queda anterior.
- Repack server-only; cliente WoW não incluído.
- Conta GM e banco preservados como estavam no momento do empacotamento.

### Instalação
Extraia o ZIP, execute 1_ABRIR_SERVIDOR_COMPLETO.bat e use um cliente WoW 3.3.5a configurado para 127.0.0.1.

Uso local / testes.
