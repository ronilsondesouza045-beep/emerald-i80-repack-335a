# Segurança

Este repack foi preparado para uso local.

Se você decidir tornar o servidor acessível por rede/Internet:

1. Altere todas as senhas padrão.
2. Revise contas e permissões GM.
3. Configure firewall e exponha somente as portas necessárias.
4. Faça backup do banco.
5. Revise as proteções/anticheat adequadas ao seu ambiente.

As credenciais do banco e da conta GM não são documentadas publicamente neste repositório.
